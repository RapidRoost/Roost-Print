Roost Print
===========

Rapid Roost's slicer, built on Creality Print.

To start: double-click RoostPrint.exe.

The first time:
- Your printers are already set up: Creality K2 Plus and Creality K1C (0.4 mm nozzles).
- Roost Print keeps its own settings, so it doesn't touch a normal Creality Print install.
- If Windows asks about WebView2, say yes: some pages in the app need it.

PrintCam:
- The PrintCam tab (top bar, next to Device) shows the shop's cameras.
- Roost Print starts PrintCam for you if it's on this computer (usually C:\PrintCam).
- If it can't find it, press "Find PrintCam.exe" in that tab.
